## 一句话说明

Maestro 是一个 AI 任务指挥台。你说一句"帮我修个 bug"，它就指挥一群 AI 帮你干活，干完了叫你。

## 没有 Maestro vs 有了 Maestro

**以前（你得一直盯着）：**

```
你 ──→ 打开 AI ──→ 等它干活 ──→ 它卡住了问你 ──→ 你回答 ──→ 继续等 ──→ ...
       （窗口不敢关，人不敢走）
```

**现在（派完就走）：**

```
你 ──→ 说一句话 ──→ ☕ 去喝咖啡
                        │
                        ▼
                   Maestro 在后台：
                   ① 拆任务 ② 派给 AI ③ 盯着干活
                   ④ 自动测试 ⑤ 干完了
                        │
                        ▼
                   通知你回来收结果 ✅
```

## 三个最实用的本事

**1. 关掉窗口，活儿照跑** 💤

```
合上电脑 / 断网 / 甚至程序崩溃
        ↓
   任务现场原样保留
        ↓
   重新打开，接着干
```

**2. 省钱** 💰

```
简单的活儿 → 派给便宜的 AI
复杂的活儿 → 才动用贵的 AI
干得不好 → 自动换更厉害的重来
        ↓
   目标：比全程用最贵的 AI 省一半钱，效果一样
```

**3. 一个"收件箱"处理所有事** 📮

AI 干活中途想问你的问题，全都汇总在一个列表里。像回消息一样，一条条点掉就行。

## 出问题怎么办？有"刹车"和"后悔药" 🛑

```
发现 AI 跑偏了
        ↓
按一下"急停"
        ↓
所有 AI 立刻定格（<0.1 秒），现场拍个快照
        ↓
你来决定：继续干 / 回滚重来 / 就此放弃
```

## 它能指挥哪些 AI？

Claude Code · Codex · Gemini · Amp · OpenCode —— 都支持，随时换。

## 30 秒上手

```bash
# 安装（需要 Rust 环境）
git clone https://github.com/yuanzimu/maestro.git
cd maestro && cargo build --workspace

# 启动
cargo run -p maestro-daemon

# 派个活儿
cargo run -p maestro-cli -- task create \
  --title "修登录页" \
  --prompt "把登录按钮改成圆角" \
  --workdir /你的项目路径

# 然后……你就可以去喝咖啡了 ☕
# 想偷看进度的话：
cargo run -p maestro-cli -- status
```
